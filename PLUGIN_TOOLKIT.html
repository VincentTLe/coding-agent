Plugin Toolkit của bạn

13 plugin đang bật (marketplace claude-plugins-official) + GSAP vừa thêm. Đây là từng cái làm gì và dùng sao cho tối đa với dự án coding-agent của bạn. ⭐ = hợp nhất ngay lúc này.

① Cốt lõi cho coding-agent — dùng cho mọi thay đổi/nâng cấp

superpowers ⭐ ★

Bộ "kỷ luật kỹ thuật": brainstorming, writing-plans, test-driven-development, systematic-debugging, verification-before-completion, dispatching-parallel-agents, using-git-worktrees, code-review.

→ Dùng: systematic-debugging cho việc audit no_action; brainstorming+writing-plans trước mỗi nâng cấp; verification-before-completion trước khi nói "xong" (đúng nguyên tắc verify của bạn).

context7 ⭐ (MCP)

Kéo tài liệu mới nhất của thư viện/SDK (vLLM, OpenAI SDK, Unsloth, GSAP…) — không dựa vào trí nhớ model.

→ Dùng: đúng Rule A "verify external/versioned" của bạn — khi đụng flag vLLM / tham số API / cách fine-tune, hỏi context7 trước.

feature-dev ⭐

Phát triển tính năng có kiến trúc, 3 agent: code-explorer (hiểu code), code-architect (blueprint), code-reviewer.

→ Dùng: khi thêm tính năng (vd finish-tool, best-of-N): explorer hiểu trước → architect lên kế hoạch → review sau. An toàn cho code đã thành hình.

code-simplifier (agent)

Đơn giản hoá code vừa sửa cho rõ ràng, dễ đọc, giữ nguyên hành vi.

→ Dùng: chạy sau mỗi thay đổi để giữ "owner giải thích được từng dòng".

code-review

Soi diff hiện tại tìm bug/logic sai/lỗ hổng, lọc theo độ tự tin.

→ Dùng: trước mỗi lần commit thay đổi vào agent.

② Verify & Web — hợp việc làm HTML / present của bạn

playwright ⭐ (MCP)

Điều khiển browser thật: navigate, screenshot, click, đọc console/network.

→ Dùng: THAY cái hack cached-chromium mình hay xài — verify deck/explainer HTML trong browser thật (đúng rule verify-in-browser).

chrome-devtools-mcp

Debug web sâu qua Chrome DevTools: a11y, performance/LCP, network, rò rỉ bộ nhớ.

→ Dùng: khi HTML/slide phức tạp — kiểm tra tốc độ tải + a11y của deck Thứ 6.

frontend-design

Thiết kế UI/HTML "chất", tránh vẻ AI generic.

→ Dùng: làm TALK.html / explainer đẹp và phân biệt hơn.

③ Quản lý & tự động hoá

claude-code-setup ⭐

claude-automation-recommender: phân tích repo, gợi ý hooks / subagents / skills / MCP nên dùng.

→ Dùng: chạy trên coding-agent để lấy gợi ý hook — đúng cái bạn muốn để tận dụng Claude Max (vd hook tự chạy test sau khi sửa).

claude-md-management

Audit + cập nhật các file CLAUDE.md / AGENTS.md.

→ Dùng: giữ ~/AGENTS.md + CLAUDE.md (vừa siết) luôn chuẩn khi project đổi.

github

Thao tác GitHub: PR, issue, review trong luồng.

→ Dùng: đổi sang làm qua PR thay vì push thẳng main — an toàn hơn trước Thứ 6.

skill-creator

Tạo / sửa / tối ưu / eval skill.

→ Dùng: làm skill riêng cho project, vd /start-vllm, /run-eval, để khỏi gõ lại lệnh dài.

④ Nâng cao — cẩn thận

ralph-loop ⚠️

Chạy vòng lặp agent tự động trong session (kỹ thuật "Ralph": cứ lặp tới khi xong).

→ Dùng: mạnh nhưng tốn token + rủi ro chạy lạc. Chỉ cho task dài, rõ ràng (vd chạy eval nhiều vòng). Tránh dùng vào code demo ngay trước Thứ 6.

⑤ Mới thêm — cần BẬT

GSAP skills: marketplace đã add, plugin CHƯA bật Bật bằng một lệnh: /plugin install gsap-skills@gsap-skills. Gồm 8 skill animation web (tweens, timeline, ScrollTrigger, plugins, react, performance…). Hữu ích để làm HTML/slide động hơn — nhưng độc lập với agent Python, và đừng nhồi animation nặng vào deck Thứ 6.

🎯 Phối hợp để tối đa hoá

Quy trình 1 nâng cấp AN TOÀN (dùng cho mọi thay đổi từ giờ tới Thứ 6)
brainstorming→ writing-plans→ freeze (git tag)→ feature-dev / code-architect→ code→ code-simplifier→ code-review→ verification-before-completion→ playwright verify + HTML dạy học→ /handoff
(superpowers lo các bước "brainstorm/plan/verify"; feature-dev lo kiến trúc; context7 lo tài liệu chính xác; playwright lo verify browser.)
Combo cho việc đầu tiên — audit no_action systematic-debugging (superpowers) để dẫn dắt phân tích + context7 kéo tài liệu vLLM/hermes tool-calling + playwright verify file HTML giải thích kết quả. Không đụng code demo.
